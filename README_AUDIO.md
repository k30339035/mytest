# 🎧 8살 아이 영어 단어 학습 오디오 샘플

## 📋 개요

8살 아이를 위한 영어 단어 학습용 MP3 오디오 파일 컬렉션입니다.
총 **104개**의 오디오 파일이 생성되었습니다.

## 📚 단어 목록 (10개)

1. **apple** (사과)
2. **ball** (공)
3. **cat** (고양이)
4. **dog** (개)
5. **elephant** (코끼리)
6. **fish** (물고기)
7. **house** (집)
8. **ice cream** (아이스크림)
9. **jump** (점프하다)
10. **kite** (연)

## 🎙️ 목소리 옵션

각 단어는 다양한 영어 억양과 속도로 제공됩니다:

### 억양 종류
- 🇺🇸 **미국 영어** (us)
- 🇬🇧 **영국 영어** (co_uk)
- 🇦🇺 **호주 영어** (com_au)
- 🇨🇦 **캐나다 영어** (ca)

### 속도 옵션
- ⚡ **보통 속도** (normal) - 일반적인 말하기 속도
- 🐢 **느린 속도** (slow) - 학습용으로 천천히

## 📁 파일 구조

```
audio_samples/
├── 01_us_normal_apple.mp3        (미국 영어, 보통 속도)
├── 01_us_slow_apple.mp3          (미국 영어, 느린 속도)
├── 01_co_uk_normal_apple.mp3     (영국 영어, 보통 속도)
├── 01_co_uk_slow_apple.mp3       (영국 영어, 느린 속도)
└── ...
```

**파일명 규칙:**
```
번호_억양_속도_단어.mp3
```

## 🎮 사용 방법

### 방법 1: 웹 플레이어 사용 (추천)

1. `audio_player.html` 파일을 웹 브라우저로 열기
2. 각 단어의 "보통" 또는 "느림" 버튼 클릭
3. 다양한 억양을 비교하며 듣기

### 방법 2: 직접 재생

`audio_samples` 폴더에서 원하는 MP3 파일을 직접 재생하세요.

## 🔧 생성 방법

이 오디오 파일들은 **Google Text-to-Speech (gTTS)** 라이브러리를 사용하여 생성되었습니다.

### 다시 생성하려면:

```bash
# 기본 10개 단어 (Google TTS)
python create_word_audio.py

# 다양한 억양으로 생성
python create_more_voices.py
```

## 📝 참고사항

- 모든 오디오는 무료 TTS 서비스로 생성되었습니다
- 성인 목소리로 생성되었으며, 아동 목소리는 포함되지 않았습니다
- 더 자연스러운 아동 목소리가 필요한 경우 유료 서비스 추천:
  - Amazon Polly (아동 음성 지원)
  - Google Cloud Text-to-Speech (다양한 음성)
  - Microsoft Azure TTS
